# Version 0.1 - Topologie de base

## Objectif

Construire la première topologie du réseau de Ndione Technologies dans Cisco Packet Tracer.

## Équipements installés

- 1 routeur Cisco 2911 nommé R1
- 2 commutateurs Cisco 2960 nommés S1 et S2
- 2 ordinateurs pour la réception
- 2 ordinateurs pour l’administration
- 2 ordinateurs pour le service informatique
- 1 imprimante réseau
- 1 serveur interne

## Noms des appareils

- R1
- S1
- S2
- PC-REC-01
- PC-REC-02
- IMP-REC-01
- PC-ADM-01
- PC-ADM-02
- PC-IT-01
- PC-IT-02
- SRV-INTERNE-01

## Branchements

| Appareil       | Interface          | Équipement | Interface          |
|----------------|--------------------|------------|--------------------|
| PC-REC-01      | FastEthernet0      | S1         | Fa0/1              |
| PC-REC-02      | FastEthernet0      | S1         | Fa0/2              |
| IMP-REC-01     | FastEthernet0      | S1         | Fa0/3              |
| PC-ADM-01      | FastEthernet0      | S2         | Fa0/1              |
| PC-ADM-02      | FastEthernet0      | S2         | Fa0/2              |
| PC-IT-01       | FastEthernet0      | S2         | Fa0/3              |
| PC-IT-02       | FastEthernet0      | S2         | Fa0/4              |
| SRV-INTERNE-01 | FastEthernet0      | S2         | Fa0/5              |
| S1             | GigabitEthernet0/1 | S2         | GigabitEthernet0/1 |
| R1             | GigabitEthernet0/0 | S1         | GigabitEthernet0/2 |

## État des connexions

- Les connexions des appareils finaux sont actives.
- La connexion S1-S2 est active.
- La connexion R1-S1 est rouge.
- Le lien R1-S1 sera activé après la configuration de R1.

## Travail non réalisé dans cette version

- Aucune adresse IPv4.
- Aucune passerelle.
- Aucun VLAN personnalisé.
- Aucune configuration Cisco IOS.
- Aucun test ping.
