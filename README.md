# Ndione Technologies - Projet réseau

## Auteur

El-Hadji Djiby Ndione

## Présentation

Ce projet consiste à construire progressivement le réseau informatique d’une entreprise fictive appelée Ndione Technologies avec Cisco Packet Tracer.

Le réseau comprend actuellement :

- une réception;
- un service administratif;
- un service informatique;
- un routeur;
- deux commutateurs;
- six ordinateurs;
- une imprimante réseau;
- un serveur interne.

## Objectif final

Le projet intégrera progressivement :

- l’adressage IPv4;
- la configuration Cisco IOS;
- les sous-réseaux;
- le routage statique;
- les VLAN;
- les trunks;
- STP;
- OSPF;
- DHCP et DNS;
- NAT/PAT;
- les ACL;
- SSH;
- la sécurité des ports;
- des exercices de dépannage.
